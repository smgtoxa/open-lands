Open Lands
==========

Open Lands plays Lands of Lore: The Throne of Chaos (Westwood Studios, 1993) from your own copy of the game,
with a new interface and optional new features (a camp, crafting, the Imp's Pit, a journal, a guide and more).

The game's files are NOT included. You need your own copy of Lands of Lore: The Throne of Chaos (for example
the GOG release). On the first start Open Lands asks where the game is installed and reads its data from there.

Windows
  Unpack OpenLands-Windows.zip anywhere and run OpenLands.exe.

Linux (64-bit)
  tar -xzf OpenLands-Linux.tar.gz
  cd OpenLands
  chmod +x OpenLands.x86_64
  ./OpenLands.x86_64

Saves and settings are kept in:
  Windows: %USERPROFILE%\AppData\LocalLow\open_lands\Open Lands
  Linux:   ~/.config/unity3d/open_lands/Open Lands
